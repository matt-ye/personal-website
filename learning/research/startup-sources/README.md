## 使用規則

1. **引用前再開一次連結**：驗證是 2026-11-16 的快照，網頁會改版或轉址。
2. **授權**：明文開放的只有 MIT OCW（CC BY-NC-SA 4.0）與 YC SAFE primer（CC BY-ND）；Steve Blank 講義寫「Creative Commons license applies」但未寫變體；
   Stanford eCorner 條款新舊矛盾。**其餘一律視為保留著作權：只放連結、年份與自己的話寫的註解，不複製內文、逐字稿，不整篇翻譯。**
   Paul Graham 的翻譯需附原文網址並通知他（見 gfaq.html），偏好連結而非鏡像。
3. **WSJ、HBR 等付費牆**：只列書目與官方頁，標注 paywall。
4. **不要寫的結論**：本批沒有任何可驗證的台灣新創同儕審查論文，專欄不可寫「已有學術證據顯示台灣……」。
5. 週次編號 W 指 `learning/` 的管理 3R 課綱，不是 `curriculum/`（投資課綱）。
