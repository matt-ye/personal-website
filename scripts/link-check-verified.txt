# 健檢跑出來的非 2xx 是「對方不讓機器看」，不是「頁面不存在」。
#
# 為什麼需要這個清單：2026-07-26 追查時發現 support.google.com 對 GitHub Actions
# 的機房 IP 一律回 **404**（不是 403）。決定性證據是 support.google.com/analytics/?hl=en
# ——GA 說明中心的首頁——也回 404。首頁不可能不存在，所以這個 404 是擋機器人，
# 光看狀態碼分不出「頁面不在」和「你不是真人」。
#
# 驗證方式：用搜尋索引比對，確認網址原封不動出現在結果裡、而且標題與頁面上的
# 連結文字相符（例：answer/9327974 →「[GA4] Funnel exploration」，站上寫「漏斗探索官方說明」）。
# 語法：一行一個網址，# 開頭是註解。
