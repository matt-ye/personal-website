# 為什麼需要這個清單：2026-07-26 追查時發現 support.google.com 對 GitHub Actions

# 連結文字相符（例：answer/9327974 →「[GA4] Funnel exploration」，站上寫「漏斗探索官方說明」）。
#
# 2026-08-08：owner 用真人瀏覽器把 CI 標成「需人工確認」的 58 條全部點過一輪，
# 結論與這份清單一致——這裡的每一條都打得開。所以底下寫的「已人工確認正常」
# 不是推論，是真的有人點過。唯一被點出打不開的是 investopedia 的 cookthebooks.asp，
