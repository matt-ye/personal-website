# 手刻頁的英文翻譯素材

這裡放 one-more-step 與紀念頁的「中文原句 → 英文」對照表，供之後做英文版遷移時套用。
**這些檔案本身不會影響網站輸出**——要等遷移時由腳本讀取、把中文包成
`zh-only`/`en-only` 成對 span（或補進頁面自己的字典）才會生效。

## 為什麼先翻譯、後遷移

這批頁面彼此沒有共用模板，雙語機制各做各的（見 `StaticPageContent.astro` 的說明）。
先把翻譯做完，遷移時就只剩機械套用，兩件事不會互相卡住。

## 檔案形狀

每頁一個 `.mjs`，匯出 `MAP`：

```js
export const MAP = {
  '中文原句': 'English',
};
```

用 `.mjs` 而不是 `.json`，是為了能寫註解——**片段的處理需要說明**（見下）。

## ⚠ 片段：不能逐條直譯

不少字串是被 `<strong>`／`<span>` 切斷的句子片段，例如：

```html
<p>重點是<strong>針對特定受眾</strong>提供具體可執行的知識</p>
```

抽出來會是三條獨立字串。**中英語序不同，逐條直譯拼回去會壞掉**，所以這些地方的
英文是「重新分配過」的——每一條負責的內容不一定和中文那條對齊，但**拼接後讀起來正確**。

改動任何一條片段時，要連同前後片段一起看。

## 姓名不翻

紀念頁的悼念留言含署名（已公開在頁面上）。**姓名一律原樣保留**，
對照表裡不放姓名條目。留言板 `#boardWall` 是從 Google Sheet 即時抓的，
不在版控裡，也不在翻譯範圍內。
